# 共同生活与民主

三部相互关联、但也可独立阅读的中文理论书稿。公开发布，持续修订。

## 书稿

### 一、《国家民主论：权利优先的双回路多中心民主》

讨论民主、国家能力、权利审查与多中心治理：在持久分歧中，民主制度如何生产约束、授权行动、分配责任并纠正错误。

当前版本：独立理论与制度纲要 v2.2（二〇二六年十月）

- [PDF 全文](pdf/国家民主论：权利优先的双回路多中心民主.pdf)（43 页）
- [Markdown 源稿](texts/国家民主论：权利优先的双回路多中心民主.md)

### 二、《共同生活论：社会再生产、日常权力与人的自由发展》

讨论社会再生产、日常权力、照护与依赖中的自由：当退出失灵、共同生活无可回避时，自由如何可能。

当前版本：二〇二六年十月

- [PDF 全文](pdf/共同生活论：社会再生产、日常权力与人的自由发展.pdf)（49 页）
- [Markdown 源稿](texts/共同生活论：社会再生产、日常权力与人的自由发展.md)

### 三、《民主协作经济论：权利有限的多元社会所有与参与型计划》

讨论经济民主、社会所有、参与型计划与制度边界：政治民主之后，经济权力如何受到权利与民主的双重约束。

当前版本：二〇二六年十月

- [PDF 全文](pdf/民主协作经济论：权利有限的多元社会所有与参与型计划.pdf)（51 页）
- [Markdown 源稿](texts/民主协作经济论：权利有限的多元社会所有与参与型计划.md)

## 阅读说明

三部书相互呼应：国家民主论确立权利优先与多中心治理的政治框架，共同生活论把这一框架推进到家庭、照护与日常依赖，民主协作经济论则处理生产资料社会所有与参与型计划。每一部均有独立的问题意识和完整论证，可以单独阅读。
